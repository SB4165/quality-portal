# 품질팀 업무 포털 — 앱 입구

https://sb4165.github.io/quality-portal/

- 휴대폰/PC에 포털을 앱처럼 설치하는 입구 페이지(PWA). 설치한 아이콘으로 열면 포털(/exec)로 바로 이동합니다.
- 포털을 새 버전으로 배포해도 이 저장소는 고칠 필요가 없습니다. (포털 /exec 주소·앱 이름·아이콘·안내 문구가 바뀔 때만 수정)
- 아이콘: `tools/make_icons.py`가 부적합 변환기 아이콘의 M 배지를 Q로 바꿔 `icons/`에 만듭니다 (GitHub Actions `Build icons`).
